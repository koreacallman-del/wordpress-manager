# SEO 글 규칙

## 구조
- H1 하나(제목). H2/H3는 **질문형** 또는 동사형. 각 소제목 바로 아래 첫 문장이 **직접 답**.
- 첫 문단 = 글 전체의 결론. 서론·인사 없음.
- 개인 상황별 분기(표: 상황 / 적용 / 예외), 실제 숫자 예시 2~3개, 경계 사례("이럴 땐 다름"), 최신 규정·개정일, FAQ 5~10개.
- 내부 링크 2~3개(관련 글·도구). 외부 링크는 1차 출처.
- 메타 디스크립션 150자 이내, 타깃 키워드 포함. 제목 60자 이내.
- 이미지 alt 개별 작성. 해시태그 나열 금지.
- 분량: 주제가 요구하는 만큼. 기본 한국어 3,000~5,000자 / 영어 1,200~2,000단어. 늘리기 위한 늘리기 금지.

## 검색 의도
- 정보형(무엇/왜) → 답 + 분기 + 도구 연결. 거래형(추천/비교/가격) → 비교표 + 판단 기준. 내비게이션형 → 쓰지 않음.
- 타깃 키워드 1개 + 연관 3~5개. 키워드 반복 금지(자연스럽게).

## 신뢰 신호
- 저자·사이트 소개, 출처, 개정일. 실무 경험이 없는 YMYL 주제는 규정·공식 문서 인용으로 대체하고 "확인 필요"를 남기지 않은 글만 게시.
