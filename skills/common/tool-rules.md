# 도구·계산기 규칙

## 판별 공식 (만들기 전 채점)
| 질문 | 점수 |
|---|---|
| 정답이 하나로 정해지는가? | +2 |
| 답이 법·규정·표준에 의존하는가? | +3 |
| 국가/지역마다 답이 다른가? | +3 |
| 사용자가 자기 고유 숫자를 넣어야 하는가? | +2 |
| 틀리면 손해가 나서 검증하고 싶은가? | +2 |
| 서버 없이 브라우저에서 계산되는가? | +2 |
| ChatGPT에 물어 바로 신뢰 가능한가? | −4 |
| 대형 사이트가 무료로 배포 중인가? | −4 |
| 구글 검색창 자체 위젯이 있는가(환율·단위 등)? | −3 |
+8 이상 만듦 / +4~7 보류 / +3 이하 안 만듦.

## 원칙
- 도구는 순위를 만들지 않는다. 구글은 텍스트를 읽는다. 도구 밑에 해설 텍스트(읽기 7~9분)가 필수.
- 코드는 5분이면 복제된다. 해자는 규정 최신성 + 텍스트 깊이 + 도메인 권위.
- 클라이언트 JS(서버·API 없음): 즉시·무제한·무비용. 카피에 "AI"를 쓰지 않는다.

## 도구 페이지 텍스트 8단
1 도구 → 2 계산 공식 + 근거 규정(조문·시행일) → 3 실제 숫자 워크스루 3개 → 4 이 계산이 안 맞는 경우 → 5 국가·기관별 비교표 → 6 개정 이력(날짜) → 7 FAQ 8~10 → 8 관련 글 링크.

## 기술
- 계산 상태를 URL 파라미터로(공유 가능) + canonical. `<label for>`. 천단위 포맷은 숫자 상태에서. 구조화 데이터 SoftwareApplication. 텍스트를 접지(`<details>`) 않음. 워드프레스에는 "사용자 정의 HTML" 블록으로 붙이고, CSS/JS 인라인.
